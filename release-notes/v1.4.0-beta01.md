# Allervue 1.4.0-beta01

## Discovery and personalization
- Added a **Picked for You** shelf to Discover.
- Recommendations are ranked locally using Jellyfin watch history and favorites.
- Excludes already-watched titles, favorites, duplicate candidates, and explicitly excluded IDs from the recommendation results.
- Adds a rating-based starter ranking when a user's viewing history is empty.
- Uses the current device year for the modest recency preference.

## Playback and adaptive improvements
- More reliable matching of requested audio and subtitle tracks by stream ID, normalized language, then title.
- Applies the matched Media3 track index rather than assuming the first track.
- Improves visible DPAD focus treatment and TV catalog sizing.
- Preserves adaptive tablet navigation and layout behavior.

## Validation
- GitHub Actions run #894 passed JVM regression tests, debug APK compilation, APK verification, and artifact upload.
- Physical validation remains necessary; Android TV remote-control acceptance is still pending.
- This is a beta debug build, not a signed production release.
